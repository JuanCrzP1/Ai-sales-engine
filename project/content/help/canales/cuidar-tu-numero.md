La conexión por código QR **no es oficial**: funciona como WhatsApp Web. Para cuidar tu número:

- Úsala con el número de **WhatsApp Business** de tu negocio.
- **Evita los envíos masivos.** WhatsApp puede bloquear los números que los hacen.
- Deja que el asistente responda a quien te escribe; no lo uses para escribirle primero a muchas personas.

## La API oficial de Meta

Es para empresas verificadas por Meta, con número propio. Aparece en [Canales](panel:canales) como **Próximamente**.
