Cada persona del equipo tiene un rol, y el rol decide lo que ve en el panel.

| | Dueño | Administrador | Asesor |
|---|---|---|---|
| Atender chats, clientes y registrar ventas | ✓ | ✓ | ✓ |
| Usar las respuestas rápidas | ✓ | ✓ | ✓ |
| Reportes y anular ventas | ✓ | ✓ | — |
| Asistente IA, probar y publicar | ✓ | ✓ | — |
| Inteligencia artificial, Canales e Integraciones | ✓ | ✓ | — |
| Atención humana y crear respuestas rápidas | ✓ | ✓ | — |
| Equipo: invitar, cambiar roles y quitar | ✓ | ✓, menos a los dueños | — |
| Eliminar el negocio | ✓ | — | — |

## Las reglas

- El negocio siempre tiene **al menos un dueño**.
- **Solo un dueño** nombra otros dueños o les cambia el rol.
- Nadie cambia su propio rol ni se quita a sí mismo del equipo.

## Lo que ve un asesor

Su menú tiene Inicio, Conversaciones, Clientes, Ventas, Ayuda y Configuración (donde solo ve las respuestas rápidas). Si abre una pantalla que su rol no permite, el panel le dice por qué y lo lleva a Conversaciones.

## Agentes de IA

Un agente de IA (Claude, ChatGPT…) solo trabaja en los negocios donde quien lo conectó es dueño o administrador. Si esa persona pasa a asesor, su agente deja de entrar a ese negocio. Ver [Agentes de IA](agentes-de-ia).
