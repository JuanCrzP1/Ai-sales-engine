[Integraciones](panel:integraciones) es un catálogo, como en las plataformas grandes:

- **Pestañas por categoría:** Todas, Inteligencia artificial, Plataformas, Agentes de IA y Seguridad.
- **Un buscador** para encontrar una integración por su nombre.
- Las tarjetas agrupadas en **Activas** (conectadas en este negocio), **Disponibles** (listas para conectar) y **Próximamente** (en camino), cada una con el logo del servicio.

## Lo que encuentras

- **La IA de tu asistente (OpenRouter):** ver [Pon tu clave de IA](clave-de-openrouter).
- **La API del asistente:** para conectarlo a otras plataformas de atención. Ver [Conecta tu asistente a otra plataforma](api-del-asistente).
- **Agentes de IA (MCP):** para que Claude, ChatGPT u otros trabajen contigo. Ver [Agentes de IA](agentes-de-ia).
- **Claves de API:** todas tus claves, con lo que puede cada una. Ver [Tus claves de API](claves-de-api).
