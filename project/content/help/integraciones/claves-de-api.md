Cada clave deja que otra plataforma o un agente de IA trabaje con tus negocios, **solo con lo que le permitas**. En [Integraciones → Claves de API](panel:integraciones/claves) ves las de este negocio y las de tu cuenta que entran a él.

## Al crear una clave

- **Su nombre**, para reconocerla (por ejemplo, «Leona» o «Claude de Ana»). Crea una para cada plataforma o agente.
- **Qué puede hacer, por área:** sin acceso, ver, o ver y editar.
- **A qué negocios entra:** este, todos o algunos.
- **Cuándo vence:** 30 días, 90 días, 1 año o «No vence».

> **Importante:** la clave se muestra **una sola vez**, al crearla. Cópiala y guárdala en la plataforma donde la vas a usar.

## Revocar una clave

Si una clave se filtró o ya no la usas, **revócala**: deja de funcionar al instante. En la lista ves cuándo se usó cada una por última vez.

Las conexiones de Claude o ChatGPT por inicio de sesión también aparecen aquí, con el nombre del agente, y se revocan igual. Ver [Conecta Claude o ChatGPT sin clave](conectar-claude-o-chatgpt).
