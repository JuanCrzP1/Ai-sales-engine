# Evidencia histórica

Los archivos JSON de esta carpeta son **evidencia histórica**: respuestas y comprobaciones de prompts
registradas en la versión inicial del motor (commit `2bcde06`). No los genera ni los lee ningún
código ni prueba actual, y no describen el comportamiento vigente.

Las respuestas que mencionan "activar la suscripción" corresponden al tenant `asesor_ai_prod`, que
vende su servicio por suscripción a sus propios clientes. No se refieren a suscripciones del motor:
esas las administra la plataforma externa.
